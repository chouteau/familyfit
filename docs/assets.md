## Prompt exact de la mascotte

> Create a single isolated production-ready transparent PNG mascot asset for the approved FamilyFit web interface shown in the reference. The reference is the character/style authority, NOT an image to reproduce as a web screenshot. Extract/recreate ONLY the happy white athletic seagull on the top-right banner: expressive large orange beak, blue swimming goggles lifted on forehead, white feathers, dark navy wings, small orange sports suit, one raised waving wing, orange feet, friendly confident smiling face, tasteful crisp cartoon rendering with clean outlines. Show full character with a little black-and-white finish flag beside it, no background, no interface, no lettering, no logos, no border, no drop shadow outside the character. Very polished joyful illustration matching the reference character; not photorealistic, not clip art. Composition full-body centered with generous clear transparent space at edges. Intended rendered size 220px tall, details must remain legible. Actual transparent background required.
